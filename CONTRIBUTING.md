# Участие в разработке

## Быстрый старт

```bash
git clone <url> && cd Reever
npm install
powershell -ExecutionPolicy Bypass -File scripts/fetch-deps.ps1
npm run dev
```

Второй шаг обязателен. Модели Vosk (155 МБ) и нативная библиотека (83 МБ) **не хранятся в git** — скрипт скачивает их с alphacephei.com и из релизов vosk-api. Идемпотентен: повторный запуск ничего не перекачивает, `-Force` переустанавливает.

Что нужно на машине: [Rust](https://rustup.rs/), [Node.js](https://nodejs.org/), Windows 10/11. Проект собирается только под Windows — вся оболочка построена на WinAPI.

## Проверка, что всё встало

`scripts/fetch-deps.ps1` в конце сам проверяет наличие критичных файлов и завершается с кодом 1, если чего-то нет. Это важно: `build.rs` на отсутствующую DLL печатает **предупреждение, а не ошибку** — сборка пройдёт зелёной, а приложение упадёт при старте.

## Сборка

```bash
npm run dev      # разработка
npm run build    # релизный инсталлятор -> src-tauri/target/release/bundle/nsis/
```

## О чём стоит знать до первого коммита

**`npm run dev` меняет файлы репозитория.** В dev-режиме конфиги читаются и пишутся в `src-tauri/resources/`, а не в `%APPDATA%` (см. `src-tauri/src/config.rs:196-251`). Калибровка голосом дописывает фразы прямо в `src-tauri/resources/actions.json`. Проверяйте `git diff` перед коммитом — легко случайно отправить свои личные фразы.

**Скрипты PowerShell сохраняются в UTF-8 с BOM.** Windows PowerShell 5.1 читает `.ps1` без BOM как ANSI и ломает кириллицу в сообщениях. Это закреплено в `.gitattributes`; не «чините» кодировку на UTF-8 без BOM.

**Тестов в проекте нет.** Ни одного `#[test]`. Если трогаете логику разбора или матчинга (`strip_wake`, `parse`, `split_targets`, `loose_terms`, `collapse_double_root`, `Action::score`) — это чистые функции, тест на них пишется в несколько строк и очень желателен.

## Структура

| Где | Что |
|---|---|
| `src-tauri/src/recognizer.rs` | цикл распознавания (1-509) и диспетчер команд (511-821) |
| `src-tauri/src/config.rs` | настройки, алиасы, резолв путей dev↔release |
| `src-tauri/src/commands_api.rs` | 19 команд для интерфейса |
| `src-tauri/src/everything.rs` | HTTP-клиент Everything |
| `src-tauri/src/{launcher,apps,system,winutil}.rs` | запуск, перечисление приложений, системные команды, окна |
| `frontend/index.html` | весь интерфейс одним файлом, без сборки |

Подробная архитектурная документация живёт в отдельном репозитории `Reever-memory`: диаграмма потока данных, карточка на каждую подсистему, зафиксированные решения и список известных проблем.

## Стиль

- Комментарии и сообщения — по-русски, как в существующем коде.
- Комментарий объясняет **почему**, а не **что**. В проекте это соблюдается: все обходы крайних случаев Windows (`\\?\` для Vosk, drive-relative `PathBuf::join`, задвоенный корень после `expand_env`, `AttachThreadInput`) подписаны причиной прямо в коде. Не теряйте эту привычку.
- `cargo fmt` перед коммитом. Конфига `rustfmt.toml` нет — берутся дефолты.

## Известные проблемы

Список открытых расхождений (мёртвые события, неподключённый `tokens.css`, шрифт из сети в офлайн-режиме и прочее) — в `Reever-memory/MEMORY/BUGS.md`. Прежде чем чинить что-то «странное», загляните туда: возможно, это уже описано вместе с причиной.
