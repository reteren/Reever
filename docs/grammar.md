# Редактируемая грамматика команд — контракт

Пользователь сам решает, что говорить после wake-слова. Меню «Что можно сказать» на
Главной становится редактором. Правила общей работы (одно дерево, правь только свои
файлы, `cargo check --all-targets` зелёный всегда, не коммить, вопросы — через
`orca orchestration ask`) — как в `docs/voice-pipeline.md`.

## Требования пользователя (2026-09-24)

1. По умолчанию:
   - **«ривер X»** — открыть программу/ссылку (действие) **без глагола**;
   - **«ривер папка X»** / **«ривер открой папку X»** — папка на компьютере (индекс дисков);
   - **«ривер загугли X»** — Google;
   - **«ривер поиск ютуб X»** — YouTube.
2. Всё это редактируется: ключевые фразы любых намерений и само wake-слово («ривер»
   может быть чем угодно).
3. **Главное**: программы открываются без «открой», пока пользователь сам не уберёт пустую
   фразу `""` из намерения «launch». Глаголы «открой»/«запусти» по умолчанию тоже приняты,
   но не обязательны.
4. Изменения применяются **сразу**, без перезапуска.

## Модель данных — `src-tauri/src/grammar.rs` (типы и `defaults()` зафиксированы)

`Grammar { wake_words, cancel_words, intents: Vec<Intent> }`,
`Intent { id, kind: Launch|Folder|Search, label, triggers: Vec<String>, url, enabled }`.
Файл — `grammar.json` в каталоге пользовательских конфигов (как `actions.json`; в dev —
`src-tauri/resources/grammar.json`, его **не создавать в репозитории вручную** — бандлить не
нужно, дефолты в коде). `""` в `triggers` = «без ключевого слова», допустимо только у Launch.

## Разбор команды — `dispatch::route(text, grammar, actions, threshold) -> Route`

Вход — нормализованный текст **после** wake-слова. Порядок:

1. **Ключевая фраза**: `grammar.match_trigger(text)` — самое длинное совпадение среди
   непустых фраз включённых намерений, целыми словами, нечётко (`«за гугле» = «загугли»`).
   Поэтому «открой папку X» уходит в Folder, а не в Launch с «открой».
   - Folder → `Route::Folder(payload)`; Search → `Route::Search{label, url с {q}=urlencode(payload)}`;
   - Launch с явной фразой («открой X») → только пользовательские действия (НЕ system) по
     `payload`, мультизапуск «X и Y»; ничего не нашлось → `LaunchFallback(payload)`.
   - Пустой payload здесь не бывает на практике (Engine дослушивает), но → `Unknown`.
2. **Без ключевой фразы**:
   - если `grammar.allows_bare_launch()` — весь текст сравнивается со **всеми** действиями
     (пользовательские + `system`), побеждает лучший `Action::score ≥ threshold`;
     system → `Route::System`, иначе `Route::Launch`; ничего → `LaunchFallback(text)`;
   - иначе — только `system`-действия (их фразы и есть команды: «выключи комп»), ничего → `Unknown`.
3. Поиск больше не живёт в `actions.json`: `web_google`/`web_youtube` переносятся в
   грамматику при первом создании `grammar.json` (фразы, совпадающие со старыми дефолтами,
   заменяются новыми дефолтами; пользовательские — сохраняются) и удаляются из реестра;
   `merge_defaults` их больше не добавляет. Прочие `kind = "search"` действия пользователя —
   тоже переносятся в `Search`-намерения с тем же id.

`dispatch()` (с побочными эффектами) = `route()` + исполнение + логи, офлайн-режим
(Search/Folder/LaunchFallback → «офлайн-режим» в лог, `Done(false)`), подтверждение
опасных system.

## Engine и glue (координатор)

- `Engine::set_grammar(Grammar)` — wake-слова и «незаконченная команда» берутся из
  грамматики (`grammar.is_incomplete`): «ривер папка» / «ривер загугли» / «ривер поиск ютуб»
  → `WakeHeard` и дослушивание.
- glue сверяет `SharedState.grammar_version` на каждом чанке и передаёт свежую грамматику в
  Engine; отмена — по `grammar.cancel_words`.

## API — `commands_api.rs` (воркер `ui`)

- `get_grammar() -> Grammar`
- `save_grammar(grammar) -> Result<(), String>` — `validate()`, при ошибках — `Err` с
  текстами через `\n`; иначе записать в `SharedState.grammar`, `save` в `grammar_path`,
  `grammar_version += 1`.
- `reset_grammar() -> Grammar` — дефолты, сохранить, версия +1.
- Регистрацию в `lib.rs` делает координатор (сообщи имена).

## UI — `frontend/**` (воркер `ui`)

Блок «Что можно сказать» рендерится из `get_grammar()`; кнопка «Изменить» переводит его в
редактор: wake-слова (чипы, первое — основное), по строке на намерение (подпись, чипы
фраз, добавить/удалить фразу; пустая фраза показывается как «— просто назови программу»
и включается/выключается переключателем «без ключевого слова» только у launch), у поиска —
URL-шаблон, «+ свой поиск» (новое Search-намерение `search_<n>`), вкл/выкл намерения,
слова отмены, «Сброс к умолчанию», «Сохранить» с показом ошибок `validate`. Строки
system («ривер выключи комп — система, с подтверждением») и отмены показываются всегда.
Примеры в меню строятся из первого wake-слова и фраз: «ривер X», «ривер папка X»…
Стиль — Windows 7 Aero проекта. Поле wake-слов из раздела «Настройки» убрать (оно теперь
здесь); `wake_words`/`cancel_words` в `Settings` остаются только для миграции.
