# Языки распознавания, интерфейса и языковые пакеты (0.4.1–0.4.3)

Заменяет схему «GigaAM основная + вторая модель для цели + определитель языка» из
`docs/bilingual.md` и раздел «Модели» в `docs/voice-pipeline.md`.

## Что где лежит

| Модель | Языки | Где | Размер |
|---|---|---|---:|
| Parakeet TDT 110m | английский | в установщике (`resources/model`) | 130 МБ |
| Streaming zipformer small-ru | детектор «ривер» | в установщике | 28 МБ |
| Silero VAD | — | в установщике | 0,6 МБ |
| Parakeet TDT 0.6B v3 (`european`) | ru, de, fr, es, it, pt + ещё 19 европейских | скачивает установщик | 465 МБ архив, ~670 МБ на диске |
| SenseVoice small (`asian`) | zh, ja (и ko, yue) | скачивает установщик | 158 МБ архив, ~237 МБ |
| Whisper base (`lid`) | определитель языка | скачивает установщик | 198 МБ архив, ~160 МБ |

Скачанное — в `%LOCALAPPDATA%\com.troid.reever\models\<папка модели>`: обновление Reever
его не трогает, «удалить данные приложения» в деинсталляторе удаляет. Каталог —
`src-tauri/src/models.rs` (адрес, SHA-256, нужные файлы); те же значения в
`src-tauri/windows/models.nsh`, совпадение проверяет тест `installer_script_downloads_the_same_archives`.

## Установщик

Свой шаблон NSIS (`src-tauri/windows/installer.nsi` — шаблон tauri-bundler 2.11.3 с двумя
вставками) добавляет после выбора папки страницу с тремя галочками. После копирования
файлов `NSIS_HOOK_POSTINSTALL` (`models.nsh`) для каждой отмеченной:

1. `curl.exe -C -` в `<models>\<папка>.tar.bz2.part` — без окна, строка над полосой
   прогресса раз в 0,5 с показывает «N из M МБ»; обрыв докачивается при следующем запуске;
2. SHA-256 через .NET в PowerShell (`Get-FileHash` в 32-битном PowerShell не всегда грузится);
3. `tar.exe` распаковывает только нужные файлы во временную папку, затем переименование.

Ошибка не прерывает установку: Reever работает без пакета, в конце — окно со списком.
Уже скачанный пакет показан отмеченным и неактивным. Строки страницы — 10 языков
интерфейса (`models-strings.nsh`, UTF-8 с BOM). Шаблон надо переносить при обновлении
`@tauri-apps/cli` (вставки помечены «Reever:»).

## Языки интерфейса (0.4.2)

Интерфейс переведён на 30 языков: все языки Parakeet v3 и SenseVoice плюс арабский
(`frontend/i18n/locales/*.js` — окно, `src-tauri/locales/*.json` — журнал и трей; полноту
проверяют `node scripts/check-i18n.mjs` и тест `uilang`). Голосовые фразы в «» в языках без
своих команд остаются английскими. Мальтийский установщик NSIS не знает — для него
установщик на английском; кантонскому установщик показывает традиционный китайский.

Первая страница установщика — языки интерфейса: 30 галочек, английский отмечен и не
снимается, остальные по выбору. Выбор уходит программе файлом
`%LOCALAPPDATA%\com.troid.reever\ui-languages-pending.txt`: при старте `config.rs` переносит
его в `settings.ui_languages` и удаляет, а текущие языки пишет в `ui-languages.txt` — их
установщик отмечает при повторном запуске. В программе — Настройки → Интерфейс → Языки
интерфейса (любой из 30 добавляется мгновенно: переводы встроены). Выпадающий список языка
показывает только включённые; выключенный язык Windows при «как в Windows» даёт английский.

На странице моделей нельзя пройти дальше, не отметив Parakeet v3 или SenseVoice (или оба):
без языкового пакета ставить Reever бессмысленно. Уже скачанный пакет считается отмеченным.
Системные строки установщика Tauri для 13 языков, которых нет в tauri-bundler, — в
`src-tauri/windows/lang/*.nsh` (`customLanguageFiles`).

## Выбор модели (`models::plan`)

- Без пакетов — базовая английская модель.
- Один пакет распознаёт свои языки и английский (английские вставки латиницей).
- Языки из двух пакетов — только с определителем языка: `AsrSet` (`asr.rs`) отдаёт фразу
  модели по коду Whisper (фраза короче 0,7 с — первой модели; решение по началу фразы
  переиспользуется для частичных распознаваний). Без определителя работает пакет
  первого языка, остальные — в журнале «⚠ … нужен определитель языка».
- Язык без скачанного пакета пропускается; Настройки → Языки показывают «пакет не скачан»
  и не дают его добавить.

Второй модели для цели команды больше нет: `set_bilingual(None, None, Ru)`, а
`english_primary` разрешает «ривер», записанный английским словом. Короткий фрагмент
(до 1 с) дополняется 0,7 с тишины с обеих сторон: без этого v3 пишет «да» как «Da» или «D.».

## Все языки пакетов (0.4.3)

В Настройках → Языки распознавания теперь все языки пакетов: 24 языка Parakeet v3
(русский, украинский, немецкий, французский, испанский, итальянский, португальский,
польский, чешский, словацкий, болгарский, хорватский, словенский, нидерландский, датский,
шведский, финский, эстонский, латышский, литовский, греческий, венгерский, румынский,
мальтийский) и 4 SenseVoice (китайский, кантонский, японский, корейский) плюс английский.
У каждого — фразы команд (грамматика v11), «да/нет», «отмена», операции калькулятора и
фразы системных действий. Числа словами калькулятор понимает только для языков из 0.4.1;
для остальных модели обычно пишут числа цифрами. Корейский глагол, как японский, ищется
в конце фразы, частица объекта (을/를) с цели срезается.

Добавляя язык распознавания, Настройки спрашивают, добавить ли его и в языки интерфейса
(`settings.languages.offerUi`): сначала интерфейс, потом модель. В установщике та же
последовательность — страница языков интерфейса идёт перед страницей моделей.

## Команды на других языках

- Фразы — `grammar::LANGUAGE_TRIGGERS` (версия грамматики 10): обычные фразы в
  `grammar.json`, видны в редакторе, но сравниваются, только пока их язык распознаётся
  (`set_active_languages`) — иначе «apri» или «ferme» совпали бы с русской речью.
- Китайский и японский пишутся без пробелов: `normalize` делает каждый иероглиф и знак
  каны отдельным словом, фразы с ними сравниваются только точно, `join_cjk` склеивает
  цель обратно для поиска, папок и диктовки. Японский глагол стоит в конце
  («メモ帳を開いて») — `match_trailing_trigger` ищет его там и срезает частицу.
- Артикль перед целью не её часть: «abra o Telegram» → «telegram».
- «Да/нет» и «отмена» на всех языках пакетов; калькулятор знает их операции и числа
  словами (только в калькуляторе: в командах «otto» или «elf» бывают названиями).
- Системные действия получают фразы на этих языках (`LANGUAGE_SYSTEM_PHRASES`).
- Wake-слово — по-прежнему «ривер/river»; японское «リバー» добавлено в варианты.

## Замеры

Русский корпус (`cargo run --release --example eval`, 166 фраз) на Parakeet v3 без второй
модели: **163/166**, exact 140, средняя задержка 427 мс (на GigaAM + v2 + LID было 163/166,
exact 129, 456 мс). Провалы: «ривер пауза» без фонового детектора (в eval его нет) и два
английских имени папок, прочитанных русским голосом синтеза. По пути найдено и исправлено:
v3 пишет короткое «да» как «da», русское «no» — как «não» (теперь принимаются, короткий
фрагмент дополняется тишиной), «заверши» — как «завершить» (фраза добавлена).

Остальные языки — `cargo run --release --example lang_eval` (голоса piper, по два на
язык; отчёт `testdata/lang-eval-report.md`). «River» — запись «River» (Zira) или «Ривер»
(Irina) перед командой: piper читает «River» по-своему, пользователь так не скажет.

| язык | по хоткею | с «ривер» |
|---|---:|---:|
| de | 12/16 | 11/16 |
| fr | 15/16 | 14/16 |
| es | 14/16 | 14/16 |
| it | 9/16 | 10/16 |
| pt | 12/16 | 13/16 |
| zh | 13/16 | 8/16 |

Почти все оставшиеся ошибки — модель неверно слышит синтетический голос (названия программ
с акцентом: «kraum», «tierra crom»; низкокачественный голос riccardo-x_low). У китайского
с русским «Ривер» SenseVoice сбивается на всей фразе; с английским «River» — как по
хоткею. Японский не проверен: офлайн-голоса японского в sherpa-onnx нет.
