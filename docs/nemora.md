# Немора — музыкальные команды

Немора — музыкальный плеер того же автора. Если она установлена, у Reever появляются
музыкальные команды; если нет — их не видно в «Что можно сказать» и они не сравниваются с
речью. Ни кнопок, ни настроек: и в Reever, и в Неморе ничего включать не нужно.

Код — `src-tauri/src/nemora.rs`, команды в грамматике — `IntentKind::Music` с полем
`music: MusicOp` (`grammar.rs`, версия 16).

## Как Reever находит Немору

`nemora::find_mcp()` ищет `nemora-mcp.exe` по порядку:

1. переменная `REEVER_NEMORA_MCP` — путь к своей сборке Неморы (разработка);
2. запись установщика `Software\Microsoft\Windows\CurrentVersion\Uninstall\Nemora` →
   `InstallLocation` в HKCU, затем в HKLM (путь там в кавычках — они срезаются);
3. `%LOCALAPPDATA%\Nemora`.

Проверка — чтение реестра и одного файла, поэтому её не кэшируют надолго (`RECHECK` = 5 с).
Повторяется при запуске, раз в 10 с в аудио-потоке (`nemora::tick`) и при открытии главного
окна. Поставили или удалили Немору при запущенном Reever — команды появятся или исчезнут без
перезапуска, в журнале строка «Немора найдена» / «Неморы больше нет».

## Команды (по умолчанию)

| Скажи | Что произойдёт | Немора закрыта |
|---|---|---|
| `ривер включи трек X` · `включи песню X` · `play song X` | трек, за ним вся библиотека в Smart Shuffle | запускается |
| `ривер включи исполнителя X` · `play artist X` | все его песни вперемешку | запускается |
| `ривер включи альбом X` · `play album X` | альбом по порядку треков | запускается |
| `ривер включи плейлист X` · `play playlist X` | плейлист по порядку; «избранное» — избранное | запускается |
| `ривер включи музыку` · `play music` | остановлено — продолжить; играет — не трогать; иначе вся библиотека в Smart Shuffle | запускается |
| `ривер выключи музыку` · `останови музыку` · `pause music` | пауза Неморы (не переключатель) | медиа-клавиша, как «пауза» |
| `ривер смарт шаффл` · `smart shuffle` | Smart Shuffle | «Немора не запущена» |
| `ривер перемешай` · `включи шаффл` · `shuffle` | обычное перемешивание | «Немора не запущена» |
| `ривер выключи перемешивание` · `выключи шаффл` · `shuffle off` | перемешивание выключено | «Немора не запущена» |
| `ривер лайкни` · `в избранное` · `like song` | играющий трек — в избранное | «Немора не запущена» |
| `ривер что играет` · `what's playing` | «сейчас играет: исполнитель — название» в журнал | «Немора не запущена» |

Правило: команды, которые **начинают** музыку, запускают Немору (её `play` ждёт запуска до
40 с); команды, которые **меняют текущее**, её не запускают. Следующий и предыдущий трек
остаются системными командами (медиа-клавиши): Немора получает их через системные медиа-кнопки
Windows (SMTC), и они работают и с любым другим плеером.

Фразы правятся в «Что можно сказать» → «Изменить», как у остальных команд. У каждой «включи …»
есть пара «выключи …»: слова отличаются одной буквой, а сравнение нечёткое, и без пары
«выключи музыку» совпадало бы с «включи музыку» (тест `switching_on_and_off_are_never_confused`).
Команды без цели («лайкни», «что играет», «выключи музыку») выполняются, не дожидаясь полной
паузы, как команда с известной целью.

## Как выполняется команда

- Reever — MCP-клиент: запускает `nemora-mcp.exe` дочерним процессом без окна, говорит
  JSON-RPC строками по stdin/stdout (протокол `2025-06-18`), имя клиента — `Reever`. Процесс
  живёт 5 минут без дела, потом закрывается; умер — перезапускается при следующей команде.
- Внутренний канал Неморы (именованный pipe) Reever не трогает: MCP — описанный контракт, и
  nemora-mcp сам читает библиотеку без запущенной Неморы, запускает её и проверяет доступ.
- Команда идёт в своём потоке (`DispatchResult::Background`), аудио-поток не ждёт её.
  Звук успеха или ошибки — когда она закончится (`nemora::take_outcomes`).
- Сначала `app_status`: он не запускает Немору и говорит, открыта ли она и что разрешено
  агентам. «Read» или «Nothing» в Немора → Настройки → AI agents — в журнале «Немора не даёт
  агентам управлять».

### Что именно играет

- **Трек**: `search` по песням. Точное совпадение названия (с транслитерацией: «гоат» = «goat»)
  важнее, иначе первый результат — выдача Неморы уже ранжирована, опечатки, раскладку и
  кириллические чтения японского она понимает сама. Версии (slowed, reverb) пропускаются,
  если в выдаче есть сам трек. Дальше — `play` всей библиотеки с этим треком первым и
  `set_shuffle smart`: без этого `play` делает очередь ровно из переданных треков, и после
  одного трека наступила бы тишина.
- **Исполнитель / альбом**: имя или ключ из `search`, песни — `list_songs` по страницам
  (до 200 за вызов) по `artist:<имя>` / `album:<ключ>`.
- **Плейлист**: поиск Неморы отдаёт только имена плейлистов, поэтому id берётся из
  `list_playlists` (точное имя, вхождение, затем похожесть ≥ 0,85).
- «;» вычищается из запроса: Немора делит по нему запрос на несколько.

### Smart Shuffle

Немора не включает Smart Shuffle при пустой очереди и без тир-листа, отмеченного «влияет на
шаффл», а веса грузит не сразу. Поэтому Reever проверяет поле `shuffle` в ответе, через 1,5 с
перепроверяет `now_playing` и, если Smart так и не включился, включает обычное перемешивание
и пишет об этом в журнал. Любой `play` без перемешивания выключает Smart в самой Неморе —
«включи альбом» после «смарт шаффл» играет альбом по порядку.

## Что видно в Неморе

- Уведомления «Reever: …» — у воспроизведения, паузы и перемешивания; у «лайкни», следующего
  трека и громкости их нет.
- Журнал в Немора → Настройки → AI agents пишет каждую команду уровня «control» (хранит
  последние 200).
- Уровень доступа в Неморе один на всех агентов; Reever работает на её уровне по умолчанию
  («Control»).

## Проверка

```bash
cd src-tauri
cargo test --lib nemora grammar dispatch say          # разбор, пары «включи/выключи», скрытие без Неморы
cargo test --lib nemora::tests::live_read_only_calls -- --ignored --nocapture   # живой nemora-mcp, только чтение
cargo run --example nemora_probe -- "включи трек smells like teen spirit" "включи плейлист гоат"
```

`nemora_probe` проходит весь путь от фразы до найденного трека на своей библиотеке, но не
играет: очередь и плеер не трогаются.

## Не сделано

- Окна выбора при неоднозначном названии нет — играет лучший вариант, в журнале видно, какой.
- Со стороны Неморы (решает её автор): одна команда «найди и включи», тихий режим уведомлений
  или свой уровень доступа для Reever — голосовая команда пользователя, а не ИИ-агент.
